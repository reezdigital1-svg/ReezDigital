# Nicodiff v0

A small diffusion model built and trained **from scratch** by the Nico Gen Studio
project. No pretrained weights. No external APIs. Every training image is a world
the Studio engine invented itself.

## What it is

- A DDPM (denoising diffusion probabilistic model) written in plain PyTorch
  (`nicodiff.py`, one file).
- A tiny UNet of about 0.36M parameters with FiLM timestep conditioning.
- Trained on 512 procedural 32x32 nebula worlds generated by the same fBm value
  noise math that powers the Studio's realtime scenes.
- Sampling uses DDIM (eta = 0), 60 steps, so one batch of samples takes seconds
  even on a laptop CPU.

## Why it exists

Proof for a bigger idea: the Studio should generate its own visuals instead of
borrowing them. Nicodiff v0 demonstrates the complete loop, own data, own
training, own weights, own sampler, on hardware we already have.

## Usage

```bash
pip install torch numpy pillow

# fast proof run (about 90 seconds on 5 CPU cores)
python3 nicodiff.py train --steps 1500 --bs 32

# longer run, stops on a time budget
python3 nicodiff.py train --steps 10000 --minutes 8

# sample 8 worlds into sample_sheet.png
python3 nicodiff.py sample --n 8
```

The checkpoint is written to `nicodiff_v0.pt` next to the script.

## Scaling tiers

| Tier | What | Where |
|------|------|-------|
| v0 (this) | 32x32 nebula worlds, from scratch | any CPU |
| v1 | same code at 64 to 256 px + a superresolution stage | consumer GPU, no API |
| v2 | fine-tune an open-weight diffusion model on own footage | consumer GPU, no API |

Tier 2 is the photoreal path that still respects the no-external-APIs rule:
open weights, own fine-tune, our data, our machine.

## Review history

Claude (ring agent, Letter 020) reviewed the recipe and found a real bug in the
first version: linear betas 1e-4 to 0.02 at T=400 leave alpha_bar_T at 0.0175,
so the forward process never reaches pure noise. Fixed by rescaling betas by
1000/T (alpha_bar_T is now 3.6e-05). His other suggestions, also adopted:
fresh engine worlds per batch instead of a fixed 512-tile dataset, EMA of the
weights (decay 0.999) used for sampling, and clipping the predicted x0 to
[-1, 1] inside DDIM.

## Honest limits

- 32x32 tiles are a proof of method, not a product visual. The model learns the
  palette and cloud structure of our worlds, not fine detail.
- With 512 training worlds, some sample-to-training similarity is expected at
  this scale; if every generated tile is nearly identical to a training tile,
  the next step is generating more diverse worlds in the dataset, not tuning.
