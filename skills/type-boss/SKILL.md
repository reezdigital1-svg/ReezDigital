# Type Boss

Default typography is the first thing that marks work as machine-made. This skill
gives every project a deliberate type system instead of a font wish list.

## Workflow

1. **Read the brand.** Name, audience, and register: technical, playful, luxury,
   urgent. The register picks the families, not personal taste.
2. **Cast three fonts, never more:**
   - DISPLAY: headlines and hooks. High personality, used sparingly.
   - WORKHORSE: body and UI. Neutral, readable at small sizes.
   - MONO or ACCENT: labels, numbers, code, captions.
   Name the license source for each: bundled, free (Google Fonts), or paid.
3. **Set the scale.** Define sizes for hook, headline, subhead, body, label, and
   caption, each step roughly 1.25x the last. In video, set a minimum text size:
   nothing below 4 percent of frame height, ever.
4. **Set the rules that get skipped:**
   - TRACKING: display tightens, mono widens, body stays near zero.
   - LINE LENGTH: 45 to 75 characters for body text.
   - CONTRAST: text must pass WCAG AA against its actual background, measured,
     not eyeballed.
   - SAFE AREA: in video, keep text inside the middle 90 percent; platform UI
     eats the edges.
5. **Ship tokens, not vibes.** Output a token block (font files, sizes, weights,
   tracking, colors) plus a one-screen cheat sheet.

## Output contract
- CAST: three fonts with roles and license source.
- SCALE: the six sizes.
- RULES: tracking, line length, measured contrast, safe area.
- TOKENS: copy-paste block.
- CHEAT SHEET: one screen a teammate can follow without asking.

## Rules
- Three fonts is a ceiling, not a starting point.
- Every rule is measured (contrast ratio, percent of frame height), never "looks right".
- A system nobody can follow is not a system; the cheat sheet is mandatory.
